# CakePHP Mongo Plugin

The **Mongo** plugin for CakePHP applications.

## Requirements

* PHP 8.2+

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.

## Installation

You can install this plugin into your CakePHP application using [composer](https://getcomposer.org):

```
composer require crustum/mongo
```

Load the plugin:

```
bin/cake plugin load Crustum/Mongo
```
